# Shared information changes use proposals and direct changes

Tsugi no longer resolves competing shared information with trust scores. Shared information changes are made either through change proposals, which become active after two target-scope approvals or are rejected after two target-scope rejections, or through direct changes, which become active immediately while still following creator scope. Accepted proposals and direct changes are recorded in a change log, while the current active shared information is maintained as a read model for daily plans and reference views. This keeps routine school-life relays fast, avoids difficult automatic conflict detection, and preserves student-only review for ordinary proposed changes without treating shared information as official school information.
